# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

Security fixes are released for the latest minor of the current major.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/gaitco/rating-filament/security/advisories/new),
or by email to **3bdullah.ghanem@gmail.com**.

Include the affected version, a description of the issue, and steps to
reproduce it. You can expect an initial response within 7 days, and a fix or a
mitigation plan within 30 days for a confirmed vulnerability.

Once a fix is released, the advisory is published with credit to the reporter
unless anonymity is requested.
